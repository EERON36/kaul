# Kaul

Kaul is a professional case-management and documentation system for pedagogues and social-service organisations.

## Status

Early planning and architecture.

## Initial goals

- Secure client documentation
- Role-based access for administrators and pedagogues
- Client assignments
- Signed journal entries
- Documents and weekly reports
- Portable backups and data exports
- Deployment through Docker

> Kaul is currently under development and must not be used with real or sensitive personal data.
