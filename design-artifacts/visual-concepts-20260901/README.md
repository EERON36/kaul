# Kaul visual concepts — September 2026

These are three isolated, mock-only concepts for brother feedback. They are
standalone HTML files and do not import or modify Kaul production UI, schema,
data, or deployment configuration.

Open each `index.html` locally. The `Klienter` and `Klientöversikt` controls
switch between the two representative screens. All names, references, dates,
and notes are fictional.

## Concepts

- `a-conservative-refinement/` — restrained extension of the current Kaul
  language: steel-blue navigation, warm paper background, quiet borders.
- `b-modern-case-management/` — task-oriented split view with a persistent
  client context rail and a stronger current-work focus.
- `c-information-dense-workspace/` — compact professional workstation with
  structured columns, explicit metadata, and a high-signal activity rail.

Each concept has screenshots under its `screenshots/` directory. These are
visual explorations only; no winner is selected here.
