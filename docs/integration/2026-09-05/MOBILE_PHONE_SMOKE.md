# Physical-phone smoke test - updated mobile candidate

Physical iPhone/Android behavior remains unverified. Run this during the separately authorized owner/brother-testing phase with fictional data only, on the updated candidate identified in the execution board. This checklist does not authorize deployment or changes to live storage.

1. **Find a client.** Sign in, open/close the menu, then search for a fictional client. Results should follow the search controls. Open a result and return; the client-creation form should still be available below results. Repeat in portrait with the phone's larger-text setting and browser zoom where available.
2. **Check Journal entry.** Open a fictional draft and enlarge text. Read and edit the complete event date/time, open the native date/time picker, and check that the on-screen keyboard does not make the fields or Save button unreachable. Save, review and return to the draft. Confirm ordinary landscape layout too. Signing and correction may be checked only within the approved fictional workflow.
3. **Check touch Documents.** In the approved disposable test environment, select a fictional file with the phone picker, upload it, download it and verify its name/content. With an Administrator account, cancel then confirm archive. Check the resulting read-only presentation.

Record phone model, OS/browser version, text/zoom settings, candidate SHA and any failed step. Capture only fictional content; omit credentials and session details. Unexpected clipping, unreachable actions, keyboard obstruction or unclear results should be reported before owner acceptance. Automated Chromium emulation does not certify Safari, native pickers, browser chrome or physical touch behavior.
